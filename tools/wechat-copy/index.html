说明：
  • 样式来源支持 <style> 内联样式与 class/id/标签选择器；外部 <link> 样式表仅同源可读，粘贴源码时通常不受影响。
  • 会被清洗：script / iframe / form / input / video / canvas 等标签，on* 事件属性，以及 position / float / transform / animation / box-shadow / var() 等公众号不支持的 CSS。
