# Forge 平台知识

写 Skill 时只能使用下列能力。某项能力取决于场景配置时，在 Skill 里写成条件，例如"如果可以搜索网络……，否则请用户提供资料"。

## Skill 怎么被使用

- 业务会话列出已启用 Skill 的名称和 description，模型判断任务相符时加载正文，再照着执行
- Skill 工作台会话也会加载当前未发布草稿；维护者直接给出任务时，先通过 skill 工具加载本轮草稿快照并执行。修改后的新修订在下一条消息生效
- 用户在消息开头输入 /名称，可以直接指定 Skill
- references/、assets/ 中的文件不会自动读入：正文里用相对路径写明什么时候读或用，模型才会去读。skill 工具加载正文时会给出 Skill 目录，模型拼出完整路径后用 read 读取。scripts/ 由 skill_run_script 直接运行（无需确认，单次最长 5 分钟）；脚本在工作区 outputs/<脚本名>-<时间>/ 下运行，写到当前目录的文件会保留为会话文件
- assets/ 里的模板读出后照着填写，交付物再用 write 保存

## 业务会话里的工具

| 能力 | 工具 | 是否一定可用 |
|---|---|---|
| 当前时间 | 无需工具，当前日期时间已作为上下文提供 | 一定可用 |
| 读取文件 | read（工作区相对路径；关联代码与 Skill 文件用绝对路径） | 一般可用 |
| 生成与修改文件 | write（整篇写入）/ edit（局部替换），只能写会话工作区，隐藏目录不可写 | 一般可用 |
| 交付文件卡片 | present | 能写文件时可用 |
| 搜索文件 | glob / grep | 能读文件或关联了代码时可用 |
| Skill 脚本 | skill_run_script | 仅启用脚本能力的业务会话可用；直接执行，部署支持时在隔离环境中运行（Skill 目录只读，可以联网） |
| 终端命令 | bash | 看企业策略；在系统沙箱中直接执行，只能写会话工作区；每次调用是独立的 Shell，cd 不保留，换目录用 workdir 参数；拒绝提权、破坏系统、读取平台密钥与其他会话数据、下载后直接执行脚本等少数高危命令 |
| 联网 | web_search / web_fetch | 看场景配置 |
| 外部系统 | MCP 工具 | 看场景配置，名称以实际为准 |

生成报告、代码等交付物时，写成"用 write 保存为 xxx.md，再用 present 交付"。

## 界面渲染能力

- Markdown 表格、代码块会直接渲染
- mermaid 代码块渲染为流程图、时序图、架构图
- vega 代码块（Vega-Lite JSON，数据写在 data.values 里）渲染为柱状图、折线图、饼图

## 限制

- name：英文字母或数字开头，只能包含字母、数字、点、下划线、短横线，最长 64 个字符
- title：最长 120 字
- description：1–512 字
- 正文：不超过 64KB
- 附加文件：references/ 只能放 .md、.txt；assets/ 能放 .md、.txt、.json、.csv、.yaml、.html；scripts/ 只能放 .py、.js、.sh。每个目录只有一层，不能再建子目录
- 文件名：英文字母或数字开头，只能包含字母、数字、点、下划线、短横线
- 数量和大小：最多 20 个文件，单个不超过 120KB，合计不超过 512KB；业务会话中只读
- 编写会话可用 skill_test_script 在隔离环境试运行脚本；部署环境未提供隔离运行能力时会拒绝执行
- Skill 工作台用 skill_trial 加载最新草稿试用（包含本轮刚做的修改），附加文件用 skill_read_file 读取、脚本用 skill_test_script 运行；skill / read / skill_run_script 是本轮开始时的快照，本轮改过草稿后不再代表最新版本。skill_test_script 只检查单个脚本，不代表完整 Skill 已完成任务
