# Skill 骨架模板

选最接近的一种，删掉用不上的小节。

## A. 分析报告类（经营分析、问题排查、数据解读）

```markdown
# {标题}
## 适用 / 不适用
## 开始前确认（数据来源、时间范围、口径；缺了怎么问）
## 分析步骤
1. 检查数据：……（完成标准：……）
2. 计算指标：……
3. 找出异常：判断条件……
4. 归因：……
## 必须问人的情况
## 输出要求（报告结构 + 样例片段；需要图表时用 vega）
## 交付前检查
```

## B. 流程处理类（审批、工单、上线检查）

```markdown
# {标题}
## 适用 / 不适用
## 输入清单（必填项、选填项、缺少时怎么办）
## 处理步骤（每步：动作 → 判断条件 → 分支去向）
## 必须问人的情况
## 输出要求（处理结论格式 + 样例）
## 常见错误
```

## C. 内容生成类（文案、周报、方案、邮件）

```markdown
# {标题}
## 适用 / 不适用
## 开始前确认（读者、用途、篇幅、语气）
## 写作步骤
## 风格要求（要什么 / 不要什么，各举一例）
## 输出要求（结构 + 样例）
## 交付前检查
```
