# 07 · Forge 业务版实现与验收

> 2026-11-17 · 本文记录代码已实现和实际执行的检查，不将目标设计、编译通过、历史 POC 或协议夹具当成真实模型验收。

## 一、纠正后的交付对象

用户确认目标是 **我们设计的 Forge 平台前后端**。本版已将曾被错误替代的 M0 验证面板移出业务入口，提供真正的 Vue → FastAPI → Runner → dsh 应用。

当前部署使用构建后的 Vue SPA，由正式 FastAPI 在 5173 同源提供；正式 Runner 在 9000。不存在对业务请求的固定脚本成功兜底，未配置模型时返回明确状态 / 冲突。

## 二、实现与源码对应

| 功能 | 主要源码 | 当前边界 |
|---|---|---|
| 本地登录 / CSRF / 密钥加密 | `backend/src/api/core/security.py`、`routes/auth.py` | 单管理员，不是 OIDC / 企业 RBAC |

| 场景 CRUD / 不可变版本 / 试运行 / 发布 | `services/scenario_service.py`、`routes/agent_scenario.py`、`ScenarioCenter.vue` | 手动装配；当前版本须在当前模型 / 策略下试运行通过 |
| 不可变 Bundle、模型和价格快照 | `services/scenario_assembler.py`、`session_service.py` | 独立加密模型凭据快照不进入可导出的 Bundle |
| 真实模型配置与测试 | `services/settings_service.py`、`routes/model.py`、`ModelCenter.vue` | Chat Completions；真实提供商尚待用户连接 |
| 正式 dsh 内核适配 | `runner/src/kernel/dsh-kernel.ts`、`dsh-process.ts` | 每会话子进程；中止为关闭进程，不虚构原生 interrupt RPC |
| 模型出口与工具 | `runner/forge-runtime-plugin/index.js` | 4 个工具；不接受外部插件、Shell 或通用网络工具 |
| 人工审批 / 超时 / 取消 | Runner `approval/request` bridge、`routes/approval.py` | 单次批准 / 拒绝；中止 / 断流 / 重启关闭孤立工单 |

## 三、实际执行的检查

### A. 构建

- `python3 -m compileall -q backend/src`：通过。
- Runner `tsc`：通过。
- Vue `vue-tsc -b && vite build`：通过；53 个模块。
- Node 26.13.1；dsh 0.2.2-rc.1；Python 3.13。

**构建不等于运行通过。** 下列检查另行实际执行。

### B. 契约与正式 Runner（19 + 20）

`runner/scripts/contract-check.mjs`：19/19 包与公开扩展点形状检查。

`runner/scripts/check-business.mjs`：20/20。实际启动 dsh 与正式业务插件，连接临时本机 OpenAI 协议夹具，验证：

- 系统提示词 / 模型 / 工具 schema 传递、分块文本、usage（缓存输入不重复计数）。
- 工具参数分片、批准后真正写盘、拒绝后不写盘。
- 另外三个工具实际执行：当前时间、文件列表、文件读取。
- 越界路径和符号链接拒绝、审批超时默认拒绝。
- 模型 HTTP 失败显示错误；中止与同 Runner 内日志重新打开。
- 输出达到 Token 上限、没有完成原因的截断流（即使收到 `[DONE]`）、内容过滤均明确失败，保留已流式产生的文本，不误报成功。
- 归档和重新构造 Runner 后，已有产物仍可读取。

联调期间发现并修复了全局 `restrict()` 不合法、遗漏审批服务挂载、错误的 attribution 调用，以及中止待审批时向已关闭子进程回写导致 Runner 退出等问题。不是仅凭编译推断可运行。

### C. 隔离控制面集成（36）

`scripts/check-business-api.py`：36/36。使用临时认证、数据库、正式 Runner 和同一类显式协议夹具，验证：

- 未登录保护、本地登录 / 退出、CSRF、异常用户名不导致 500。
- 四个模板、官方只读、个人 CRUD / 复制 / 版本、拒绝未知能力。
- 没有模型时不能创建执行或捏造试运行记录。
- 配置密钥不回传、加密落库、拒绝元数据 / link-local 网关地址、真实 HTTP 协议测试。
- 后台执行、同会话并发 409、审批、工具结果和消息落库、用量与价格计算。
- SSE 游标、`Last-Event-ID`、完整 JSON 导出不含模型密钥。
- 模型 / 价格修改不改变已有会话；策略变化使旧发布试运行失效。
- 归档的试运行仍可审计；白名单交集阻止模型幻觉出的未授权工具。
- 中止取消审批，归档保留文件；超过 2,000 个事件不静默截断。
- 控制面初始化修复孤立任务 / 工单；实际重启 Runner 后文件可读，旧执行明确冲突。
- 场景删除不破坏历史快照；生命周期重启后历史仍在。

### D. 当前实际业务页面（22）

`scripts/check-business-ui.py`：22/22。测试真实已部署的无模型环境，不替换 API；临时测试场景在流程中软删除。

登录错误与成功、刷新保持、场景推荐填入任务、无模型引导、模型预设不自动保存、模板复制 / 编辑 / 版本 / 使用 / 删除、能力目录和 Skill/MCP 未接入提示、治理策略保存、真实空审计、6 个页面在 390px 无横向溢出、移动端退出、无 JS 异常和 API 5xx。

### E. 执行流程浏览器（8）

`python3 scripts/check-business-api.py --browser`：8/8 附加流程，使用**隔离正式业务栈 + 协议夹具**：

1. 离开运行中的会话，再回到同一会话，SSE 重连且消息不重复。
2. 实际审批卡控制文件写入，工具结果卡持久化。
3. 真实产物预览和下载内容正确。
4. 拒绝操作呈现失败结果，而不是成功状态。
5. 中止关闭审批并呈现失败原因。
6. 刷新后恢复消息、工具卡和上次失败。
7. 轨迹来源筛选、原始载荷展开、带认证 JSON 导出。
8. 执行过程中无浏览器 JS 异常。

### F. 文件边界和并发配额（21）

`runner/scripts/check-workspace.mjs`：21/21。直接调用正式插件注册的执行器，在真实临时文件系统中验证；不替代上面的 dsh / 审批集成。

256,000 字节单文件的等值 / 超限 / UTF-8 字节计量、超大文件读取、8 层 / 9 层路径、递归文件元数据、越界 / 隐藏 / NUL / 长路径、符号链接读写与列表排除、100 / 101 文件、10,000,000 字节总配额与覆盖扣减。额外检查两个并发写入不能突破文件数或总量上限；配额检查和写盘在同会话内串行化。

### G. 跨站 iframe 认证（2）

`scripts/check-iframe-auth.py`：2/2。临时证书、两个本地 HTTPS 测试域与透明转发真实已部署应用，使用浏览器原生 Cookie 处理，验证登录、Secure / HttpOnly / SameSite=None / Partitioned 属性和退出。Playwright 人工响应填充不能可靠验证分区 Cookie，因此未使用该方式作为证据。

**此检查不等于验证 Arena 的真实流量代理或外部访问。** 实际用户应从 Arena Live Preview 打开；底层 URL 可能另有流量令牌要求。

## 四、尚未完成的验收

**未提供真实模型配置 / API Key。因此：**

- 尚未针对 DeepSeek 官方 API、企业网关或其他真实提供商完成端到端验证。
- 不能宣称真实回答质量、真实服务工具兼容性、实际账单或长任务稳定性已经达标。
- 协议夹具的成功只证明工程连接与控制闭环，不代表真实模型会按要求调用工具。

另外，原设计中的 OIDC / 企业 RBAC / 多租户 / 团队空间、Skill / MCP / 项目 / 知识库、Creative 生成、结构化表单、原生 fork、执行分叉 / 重跑、跨 Runner 执行恢复、生产容器隔离、Redis / S3 / WORM / SIEM、正式数据库迁移和 20 会话压测均未完成。

当前是**可使用、已部署的单工作空间业务版本**，不是整套企业平台的生产验收完成。下一步应先接入用户真实模型，跑自由对话、工具批准 / 拒绝、文件产出及异常场景，再进入企业身份与生产基础设施建设。
