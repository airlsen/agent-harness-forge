# Forge Design System｜Color System

> 版本：1.0\
> 品牌主色：`#DA724D`\
> 设计方向：Warm Professional（暖色专业主义）\
> 适用范围：Forge 企业级 Agent 平台的 Web 端产品界面

------------------------------------------------------------------------

## 1. 设计目标与原则

Forge
的颜色体系以暖陶土橙作为品牌识别色，以中性灰作为界面骨架，并通过独立的语义色表达业务状态。

### 1.1 视觉定位

-   **专业可信**：使用清晰、稳定的深灰文字和低干扰的中性色。
-   **温暖友好**：使用 `#DA724D` 作为品牌识别色，避免高饱和荧光橙。
-   **简洁克制**：页面以白色和浅灰为主，品牌色只用于关键操作和交互状态。
-   **状态明确**：成功、信息、警告、错误使用独立语义色，不与品牌色混用。
-   **可扩展**：为
    Agent、MCP、工具、技能等不同能力类型预留辅助色，但不改变品牌主色。

### 1.2 使用比例建议

以下是视觉控制建议，不是必须精确遵守的面积比例：

  颜色类别             建议占比 主要职责
  ------------------ ---------- ----------------------------
  中性色               75%--85% 页面背景、卡片、文字、边框
  品牌色及其浅色阶     10%--15% 主要操作、选中态、关键强调
  语义色及辅助色        5%--10% 状态、提示、能力类型识别

**核心原则：品牌色负责识别和交互，不负责表达所有业务状态。**

## 6. 交互状态 Interaction

交互状态应有统一规则，避免同一个组件在不同页面出现不同的 Hover、Active
和 Focus 表现。

  状态               推荐处理
  ------------------ ----------------------------------
  Default            使用组件默认背景和边框
  Hover              背景轻微加深，或边框略微增强
  Active / Pressed   使用更深的品牌色或背景
  Selected           使用品牌浅色背景，配品牌深色文字
  Focus              使用品牌色边框，并提供清晰焦点环
  Disabled           降低对比度，禁止交互
  Loading            保留原有品牌识别，使用加载反馈

### 6.1 组件状态建议

**主按钮**

-   Default：背景 `#C65D3B`，文字 `#FFFFFF`
-   Hover：背景 `#A94B2E`
-   Active：背景 `#873B27`
-   Disabled：背景 `#F0F1F3`，文字 `#98A2B3`

**次按钮**

-   Default：白色背景，边框 `#E5E7EB`，文字 `#344054`
-   Hover：背景 `#F8F9FB`
-   Active：背景 `#F2F4F7`
-   Focus：品牌色焦点环

**分段式分类选择器**

-   外层：`#F2F4F7` 背景，圆角容器。
-   未选中：透明背景，文字 `#475467`。
-   选中：`#FCEAE2` 背景，文字 `#A94B2E`。
-   数量徽标：未选中 `#EAECF0`，选中 `#F5C7B5`。
-   Hover：未选中项使用 `#FFFFFF` 或轻微浅灰背景。
-   不使用贯穿页面的底部横线。

**输入框**

-   Default：白色背景，边框 `#D0D5DD`。
-   Hover：边框 `#98A2B3`。
-   Focus：边框 `#DA724D`，搭配轻量焦点环。
-   Error：边框 `#D64545`，错误说明使用错误深色。
-   Disabled：背景 `#F2F4F7`。

## 8. 页面应用规范

### 8.1 页面背景

-   主工作区建议使用 `--bg-page` 或白色，按页面密度决定。
-   主要内容卡片使用 `--bg-card`。
-   不建议给每个区域都增加背景色块。
-   页面背景和卡片背景之间要有轻微但可辨识的层次。

### 8.2 侧边栏

-   背景使用白色或非常浅的中性色。
-   默认菜单文字使用 `--text-secondary`。
-   当前菜单使用 `--accent-subtle` 背景、`--accent-active` 文字。
-   当前菜单图标与文字保持同一品牌色。
-   不建议给整个菜单项使用高饱和橙色背景。

### 8.3 能力管理

-   分类选择器：使用中性浅灰外层容器 + 品牌浅色选中项。
-   工具与插件图标：品牌橙。
-   技能图标：可使用蓝色。
-   MCP 图标：可使用青色。
-   发布状态：绿色。
-   草稿状态：中性灰。
-   待审核状态：黄色系警告色。
-   异常状态：红色。

### 8.4 聊天与 Agent 工作区

-   用户消息和 Agent 消息应优先使用中性背景区分。
-   品牌橙用于关键操作、Agent 状态或重要交互，不建议把整块 Agent
    消息背景染成橙色。
-   工具调用、MCP 连接、Agent 执行等状态应使用语义色或类型辅助色。
-   代码块、引用块和日志区域优先使用中性背景，确保长时间阅读舒适。

## 9. 可访问性与使用约束

1.  不要仅依赖颜色表达状态，必须配合文字、图标或其他可识别标记。
2.  小字号正文应优先使用深色文字，不要使用 `#DA724D`
    或浅色阶作为长文本颜色。
3.  白色文字搭配主按钮时，优先使用较深的 `#C65D3B`，不要默认使用较浅的
    `#DA724D`。
4.  错误、警告、成功等状态色必须保持语义一致。
5.  选中态要同时具备背景、文字或图标变化，不能只依靠色差。
6.  Focus 状态必须清晰可见，不能只在鼠标 Hover 时提供反馈。
7.  重要文本和背景应按 WCAG
    对比度要求进行检查；最终上线前使用实际字号、字重和背景组合进行验证。

## 10. 设计落地优先级

建议按以下顺序在 Forge 中落地，避免一次性改动过多：

  优先级   改造内容                            目标
  -------- ----------------------------------- ----------------------
  P0       统一品牌色、中性色、文字色          先解决全站颜色不一致
  P0       统一按钮、选中态、输入框状态        建立基本交互规范
  P1       统一成功、警告、错误、草稿标签      提升状态识别效率
  P1       统一页面背景、卡片和边框            提升整体视觉质感
  P2       建立 Agent、MCP、Skill 类型辅助色   增强能力分类识别

## 11. 最终设计决策

Forge 的颜色体系建议固定为：

-   **品牌主色**：`#DA724D`，保留现有品牌识别。
-   **主按钮色**：`#C65D3B`，增强白色文字的可读性。
-   **选中背景**：`#FCEAE2`，让选中状态温和且明确。
-   **主文字**：`#202733`，避免纯黑带来的生硬感。
-   **辅助文字**：`#667085`，保证信息层级。
-   **页面背景**：`#F8F9FB`，形成轻量的空间层次。
-   **边框**：`#E5E7EB`，弱化不必要的分割。
-   **成功 / 信息 / 警告 / 错误**：分别使用绿、蓝、黄、红。
-   **AI 辅助色**：紫色用于 Agent，青色用于 MCP，蓝色用于
    Skill；工具与插件沿用品牌橙。

**最终视觉关键词：专业、温暖、清晰、克制、可信。**

这套规范的目的不是让界面出现更多颜色，而是让每一种颜色都有明确职责，让
Forge 的不同页面看起来像同一个产品。
