# 06 · Forge 业务版沙箱部署

> 2026-11-17 · v0.2。本文件已替换早先 M0 演示面板的临时部署说明。当前入口是**我们设计的 Forge 平台前后端**，不是原生 `dsh web`。

## 1. 访问哪个入口

在 Arena 会话中打开 **「Forge 平台」Live Preview（5173）**。

- 正式入口：`backend/src/api/main.py`，同时服务构建后的 Vue SPA 和 `/api/*`。
- 独立执行面：`runner/src/server.ts`（9000），只有内部 Bearer Token 可访问执行接口。
- 旧的独立 preview API / POC Runner / M0 面板已退出业务入口，并移除未使用的旧骨架；历史 CLI 验证仍保留。
- 管理员账号及密码只在 `data/admin-login.txt`；不写入本文，不输出到启动日志。
- 直接拷贝 `*.e2b.app` 底层地址可能遇到 Arena 流量令牌校验。该地址不能承诺为匿名、永久公网链接；应使用平台 Live Preview。

```text
浏览器 → :5173 FastAPI + frontend/dist
                  └─ /api → 正式控制面
                                └─ 内部 Token → :9000 正式 Runner → dsh
```

前端只访问同源相对 `/api`，不会在用户浏览器中请求 `localhost:9000`。沙箱部署对外绑定 `0.0.0.0`，没有拒绝 `.e2b.app` Host 或阻止 Arena iframe 的响应头。

## 2. 初始化与恢复

```bash
# 本沙箱安装的较新 Node 位于此路径；其他服务器应使用自己安装的 Node >=24.9。
export PATH=/home/user/.local/node/bin:$PATH

python3 -m pip install -e 'backend[dev]'
npm --prefix runner ci
npm --prefix frontend ci
python3 scripts/setup-sandbox.py  # 不覆盖已有账号和 Token
make build
```

然后由后台进程管理器分别运行：

```bash
# 执行面
bash scripts/start-runner.sh

# HTTPS iframe 预览模式的正式前后端
FORGE_EMBEDDED_PREVIEW=1 FORGE_API_PORT=5173 bash scripts/start-api.sh
```

普通本地 HTTP 调试不设置 `FORGE_EMBEDDED_PREVIEW`。`start-runner.sh` 自动优先使用 `$HOME/.local/node/bin/node`，并校验 Node >=24.9；其他部署可用 `FORGE_NODE_BIN` 显式指定。Runner 自身也拒绝旧 Node，避免“状态在线、实际 dsh 无法运行”。开发热更新使用 `make dev-*` 三进程入口，与正式构建部署分开。

### Cookie 模式

- 普通本地开发：HttpOnly / SameSite=Strict。
- HTTPS iframe：Secure / HttpOnly / SameSite=None / Partitioned；仍强制 CSRF，不向 localStorage 暴露登录令牌。
- 已通过 Chrome 本地登录 / 刷新 / 退出，以及双本地 HTTPS 测试域的原生跨站 iframe 登录 / 分区 Cookie / 退出检查；后者透明转发真实应用，不等于验证 Arena 流量代理本身可达。旧浏览器如不支持分区 Cookie，建议从预览入口在新标签页打开。
- 单个管理员本地账号不等于 OIDC、团队角色或企业账号生命周期管理。

## 3. 首次业务使用

1. 登录，工作台默认显示「模型未配置」。没有已发生的任务时，审计中心显示真实空状态。
2. 「模型中心」填 Base URL（不含 `/chat/completions`）、实际模型 ID、可选 API Key / 价格。
3. 保存，再点击「测试已保存的连接」。这会发送真实 HTTP 模型请求，可能产生费用。
4. 返回工作台，选择官方模板或个人场景，输入自由文本任务。
5. 生成产物默认等待逐次批准；可允许、拒绝或中止。审批超时拒绝。
6. 在轨迹页查看持久化事件 / 原始载荷并导出，或在产物侧栏预览 / 下载实际文件。

**未提供真实模型连接前，不能宣称真实外部模型对话已经验收。** 工程测试使用临时数据库与本机协议夹具，和上述业务环境完全分离。

## 4. 持久化与恢复语义

| 位置 | 用途 |
|---|---|
| `data/auth.json` | scrypt 密码摘要、会话签名密钥，0600 |
| `data/admin-login.txt` | 生成的管理员登录凭据，0600 |
| `data/business.env` | Runner 内部 Token / 本地 endpoint，0600 |
| `data/encryption.key` | 模型密钥与会话模型凭据快照的加密密钥，0600 |
| `data/forge.db` 及 WAL | 场景版本、模型与策略、消息、审批、事件 |
| `runner/data/sessions/<UUID>/` | 会话工作区、运行 patch、dsh Session Log |

`data/` 为 0700；上述路径与所有运行数据均被 Git 忽略。备份时应一致备份数据库、加密密钥、认证配置和 Runner 数据；SQLite 在线备份应使用其备份 API 或停写后处理 WAL，不能只复制主文件。丢失加密密钥就不能恢复已保存的模型凭据。

- 场景与策略、模型 / 价格在会话创建时锁定；密钥快照只存在独立的加密记录，不进入前端 Bundle 或导出。
- 浏览器断开不终止后台任务；SSE 按事件序号重连，支持 `Last-Event-ID`。
- 同一 Runner 内中止后，再次执行可从 dsh 日志重新打开会话，已做夹具集成测试。
- 控制面重启时将孤立运行标记中断，并关闭待审批工单，避免永久显示「执行中」。
- Runner 进程重启后不能继续旧执行上下文；明确返回冲突，提示新建。数据库历史保留，原磁盘存在时产物仍可读取。
- 归档释放 Runner 会话槽位，保留消息、事件、本地产物。

## 5. 安全和运行限制

- **只能使用一个控制面 worker**；后台任务和会话锁当前仍在单进程内。不是多副本 HA 调度器。
- Runner 默认容量 4，空闲会话需手动归档释放槽位；没有完成 20 会话负载验收或闲置自动回收。
- 只有 4 个受限工具。原生 Shell / 工作目录切换 / 原生文件工具在业务 patch 中禁用，再由 agent 级白名单和单调拒绝 guard 限制工具调用。
- 文件路径检查禁止越界、隐藏文件和符号链接；单文件 ≤256 KB、目录深度 ≤8、每会话 ≤100 个文本产物、总量 ≤10 MB。
- 这些是进程和工具边界，**不是容器、seccomp 或微虚拟机隔离**。不允许安装任意用户代码 / 第三方插件。
- 模型网关由管理员信任配置；允许本地和企业私网网关，拒绝已知元数据 / link-local 地址，拒绝跟随 HTTP 重定向。不应视为通用 SSRF 防护网关。
- 暂未实现 OIDC / 企业 RBAC / 多租户；本地加密不是 KMS。授权用户可导出任务原文和文件，尚无企业 DLP 脱敏。
- 审计最近会话列表最多 150 条；单次轨迹接口分页，完整导出 / 只读审计会拉取全部已存事件。没有 WORM、S3、SIEM、Kafka 或自动保留期清理。
- SQLite 表结构由 `create_all` 初始化，尚无正式迁移体系；PostgreSQL override 尚未实测，不应宣称生产支持已经验收。

## 6. 验收命令

```bash
make build
make lint
make test
python3 scripts/check-business-api.py --browser
python3 scripts/check-business-ui.py --base http://127.0.0.1:5173
python3 scripts/check-iframe-auth.py  # 需当前部署使用 FORGE_EMBEDDED_PREVIEW=1
```

当前结果：契约 **19/19**；正式插件 + dsh 协议夹具 **20/20**；文件执行器与配额边界 **21/21**；隔离控制面 / Runner 集成 **36/36**；当前业务页面 **22/22**；隔离执行流程浏览器 **8/8**；双本地 HTTPS 域 iframe 认证 **2/2**。所有夹具明确标记“非真实模型”，临时数据执行后清理。

截图和机器报告在被忽略的 `data/business-checks/`，源码测试可复跑。详见 [07 · 业务版实现与验收](07-业务版实现与验收.md)。

沙箱休眠或结束会停止服务；进程、安装依赖和构建缓存不保证跨恢复存在。源码保留，长期运行需要部署到用户自己的基础设施。
