## 二、经源码+运行双重核验的 dsh 扩展点（契约基线）

| 扩展点 | 位置 | 形状 |
|---|---|---|
| 插件注册/卸载 | Cordis | `export const name / inject / apply(ctx, config)`；apply 返回 disposer，**副作用自动回滚** |
| 依赖声明 | Cordis | `export const inject = ['llm','tools']`；缺服务不激活，消失自动卸载 |
| 模型适配器 | `dsh-llm` | `ctx.llm.registerAdapter(providers, adapter)`；`LlmAdapter`：`providerInfo/providerRetryPolicy/imageRequestPricing/imageRequestTarget/listModels/resolveModel/prepareCall/attributionHeaders`；`prepareCall → {model, stream(options)}`；`context.contextWindow` |
| 流式模型协议 | `dsh-llm` | `StreamChunk`：`block-start / text-delta / reasoning-delta / tool-call-delta / block-end / usage / finish`；**finish.reason 是对象 `{kind}`**（stop/tool-calls/max-tokens/aborted/error），不是字符串 |
| 工具门控瀑布 | `dsh-tools` | `ctx.on('tools/pre-execute', (exec, next) => PreToolDecision)`；decision = `{kind:'allow|deny|cancel|ask', reason?, displayReason?}`；`next()` 即 allow |
| 工具注册 | `dsh-tools` | `ctx.tools.register({name, description, parameters(JSON Schema), output:{schema, render}, execute(args, exec)})` → 返回卸载函数 |
| 审批面 | `dsh-user-approval` | `ctx.approval` 服务；会话策略 `ask/never`，fail-closed；SDK host 可在 initialize 用 `approvalRequests:true` 接管 `approval/request` 反向调用 |
| SDK 宿主协议 | `dsh-sdk-protocol` | 换行分隔 JSON-RPC over stdio；`initialize / session/prompt / session/query / session/resume / session/wait`；未知 sessionId 自动建会话；通知 `session.event / session.status` |
| 配置叠加 | profile boot | bundles → profile patch → home patch → `--patch`（后层覆盖前层）；patch 项 = `{id, insert?}`，insert 之外按 id 合并 overrides |

## 三、踩坑记录（给后来人省时间）

1. **CLI 静默退出**：`bin.js` 用 `if (import.meta.main)` 自启动，Node 不设该字段。→ `scripts/dsh-launch.mjs` 包装器显式 `runCli()`（上游修复后删除）。
2. **Node 版本**：`engines.node >= 24.9.0`；Node 20 会在 `dsh-session-persistence-jsonl` 处因 `node:zlib` 缺 `createZstdCompress` 启动失败。→ 部署/CI 统一 Node 26。
3. **inject 必声明**：Cordis 对 `ctx.llm`/`ctx.tools` 属性访问做权限校验，未在 `inject` 声明即抛 "cannot get property without inject"。
4. **裸 class 适配器**：抽象基类的默认方法（providerRetryPolicy 等）不会被继承到裸对象，registerAdapter 会立即调用 → 需显式补齐。
5. **patch 语法**：insert 之外，非 insert 项必须带 `id`；list-of-ids 的 remove 形态不存在，删除语义在 loader journal 层（remove 记录），overlay 层做 id 合并。
