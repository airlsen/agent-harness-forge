# 09 · 企业版前端第一批：实现与验收

> 2026-11-17 · 基于《08-前端产品体验改造方案》v0.4，含最新批准的“保留工作台、对话优先”入口改造及头像账号菜单收敛。
> 本文记录实际修改和验证，不将前端展示当作企业身份、MCP 或插件平台已经完成。

## 1. 本次交付

**在现有 Forge 项目中直接完成企业版前端第一批，并由原 FastAPI 服务构建产物。不是独立原型、静态演示或 API 模拟页面。**

产品结构改为：

```text
工作台（自然语言起点）→ 首轮接受 → 持续会话 → 结果与过程
         ↕                          ↕
   独立的新建动作                 我的会话

企业场景 / 企业能力中心：稳定侧栏入口，按需发现和引用

平台管理 → 管理概览 / 模型连接 / 企业策略 / 运行审计
```

资源呈现遵循“公共能力统一发现与引用，不为个人重复安装”。本次不修改底层身份系统或把旧场景数据模型冒充已经迁移。

## 2. 实际页面

### 企业外壳

- 取消“我的工作空间”、空间选择器、DEV 与内核状态常驻主导航。
- 一级导航为工作台、企业场景、企业能力中心、我的会话。
- 最近会话最多 6 条，不无限堆叠；分组标题仅保留文字，不显示箭头或展开控件，完整记录从一级菜单“我的会话”进入。无记录时只显示一句“开始对话，记录会留在这里。”，不再拆成两行主副文案。
- 账号区只保留头像与身份，不常驻退出箭头/按钮；桌面悬停或点击、手机首触、键盘 Enter/Space/方向键均可打开向上的退出菜单。Esc 返回头像，Tab 自然离开，外部点击/切页收起；退出仍清空认证、草稿和附件，并防止重复提交。
- 平台管理独立入口，管理区提供同站二级导航和返回工作台。
- 删除重复的全局面包屑、预览徽标和指南顶栏，连同原 60–64px 占位及加载条旧偏移一并清理。
- 操作帮助移至左侧底部，复用可访问抽屉；登录、管理概览和会话列表继续保留真实身份/隔离边界。
- 登录页同步企业平台文案，原账号与认证机制不变。

### 工作台

- **保留“工作台”菜单、独立页面及默认落点**，不实施此前被否定的删除/只重定向方案。
- 右侧只保留一个“今天要完成什么工作？”标题、最大 820px 的居中共享输入、约 3 个真实轻量场景建议和必要的模型连接/失败反馈；手机和短窗口以上方可输入为先。
- 已删除首页公共能力区、最近工作区（含空状态、列表、全部记录链接）、宣传页脚、副标题、场景目录标题/链接，以及大卡片描述/来源/版本/装饰背景/悬停箭头。实际资源和会话功能继续通过侧栏进入。
- 建议仅来自真实预置/已发布场景，排除默认通用场景并最多取 3 项；维护草稿不混入，缺少就少显示，不造假占位。
- 点击建议原地选中真实场景并聚焦输入，不跳转、不自动填充/覆盖文字和附件、不自动发送、不创建会话。
- 第一次提交被服务端接受后，直接进入真实消息和底部输入，不展示第二个欢迎/选择页；新建会话的空状态也复用 `ConversationStart`。
- 模型未连接时明确提示并引导至真实配置页，不产生固定回答；没有新增模型选择/安装/模式选择门槛。
- 本轮不新增未来任务看板、待办、公告、用量/Token 统计或未来能力占位。

### 草稿与导航

- 起始任务和各个既有会话的回复分别保存文字、已读取附件、场景，SPA 导航可原位恢复；返回工作台不混入上一个会话的上下文，打开另一个会话不带入别处未发送的文字。
- `新建会话` 是明确开始独立上下文的动作；如果会覆盖未发送的起始草稿，提供取消、返回草稿和明确放弃后新建，既有会话的回复草稿不因此清空。
- 草稿只保存在当前登录标签页内存，不写入 localStorage / sessionStorage；刷新/离站请求浏览器确认，取消后保留，确认离开后不承诺跨刷新恢复。浏览器可能限制原生离开提示，不宣称持久草稿能力。
- 退出或认证失效清空草稿、附件和会话内存状态。这里是客户端上下文保护，不是已经完成服务端员工身份隔离。
- 旧提交的迟到回执只消费对应的已接受快照，不能重定向、清空或污染新草稿；历史读取失败或被取消时不拿空加载状态覆盖已停放的输入。
- 首轮请求失败后仍是起始草稿，重试可复用已创建的会话；服务端接受前不绑定可见会话，不显示无效的中止按钮。重新打开仍在提交的既有会话，先等该请求确认，再回读真实快照和续接 SSE。
- 返回工作台、新建或关闭 SSE 都不调用中止；已接受执行在后台继续，列表按真实状态结算。

### 企业场景

- 使用目录仅展示模板和已发布场景，默认主操作是查看详情、开始会话。
- 维护视图通过 `?view=maintain` 进入；不是另一份资源库。
- 预置模板只读；复制后生成维护草稿，而不是声称“安装到我的空间”。
- 现有创建、编辑、删除、版本、真实试运行与发布门槛保留。
- 新详情页展示适用工作、提示词规范、已授权工具、版本与实际维护账号；工具可跳转能力详情。
- 不把草稿保存等同于发布，不取消原有测试门槛。

### 企业能力中心

- 主内容是 4 个真实可调用的基础工具，不再把 dsh SDK 展示成可安装业务应用。
- 工具支持用途搜索、需求示例、调用范围说明、适用场景与开始入口。
- Skills/MCP 分别读取真实注册接口的 `available`、`items` 与 `reason`，如实展示尚未接入。
- 标签页支持 URL 深链接及刷新保持；工具支持 `?tool=...` 详情定位。
- 运行组件放可展开的高级信息，仍能查看真实组件版本、扩展点和权限声明。
- 无假安装、假连接、假发布或模拟第三方业务插件。

### 我的会话

- 使用现有真实会话 API，不新造任务调度模型。
- 支持标题/场景/ID 搜索，全部、执行中、可继续、异常/中止筛选。
- 明确搜索范围是接口返回的最近会话（最多 150 条），不假称全库检索。
- 运行中会话禁止在 UI 归档；结束后经确认归档。归档不删除审计证据，不提供假撤销。
- `idle` 统一展示“可继续”，不等于业务目标完成。
- 明确当前只有管理员账号，还不是员工间访问隔离。

### 会话执行

- 对话为主，结果/过程/能力详情默认收起，按需打开。
- 工具卡默认简洁，输入与结果展开查看；使用可读工具名称。
- 审批始终留在输入区前方，不藏在过程侧栏。
- 结果区显示实际文件和最近回复；文件支持读取状态、失败重试说明、真实预览与下载。
- 过程区显示实际关键事件，原始轨迹仍可进入完整页面筛选和导出。
- 显示本次冻结的场景/能力/模型快照，而非静默套用后来修改的场景。
- 不因收到部分模型输出就显示业务成功；中止、失败和部分输出继续保留。

### 实际发现并处理的交互问题

1. **离开执行页后会话状态可能滞留**：存在已知运行中会话时每 3 秒同步列表，避免用户刚收到回复便离开 SSE 页面，列表长期停在运行中。
2. **提交中的迟到响应可能影响新草稿**：按读取/提交代际检查，用户在请求途中切换会话后，不把旧消息、回执或重定向写入新会话。
3. **附件异步读取可能越过草稿切换**：附件读取绑定草稿版本与组件生命周期，旧附件不会迟到写入另一草稿。
4. **文件预览缺少读取反馈**：补充加载、失败和取消后的响应保护。测试等待实际文件响应与内容完成，而非只依赖短暂 UI 时序。
5. **窄窗口主导航隐藏且菜单错位**：按用户要求取消主导航抽屉，桌面/平板侧栏始终显示，手机改为图标与完整文字均可见的常驻窄栏。新建会话、主菜单和平台管理统一网格列及行高；移除旧版窄屏居中规则的干扰。主菜单区在短窗口独立滚动，不遮挡底部账号。模态详情仍保留焦点约束与 Esc 关闭。

6. **全局标题层级重复、装饰挤占任务区**：移除顶栏及预留高度，加载条归零；工作台、目录、会话列表与管理表单共用标题/间距/宽度规则。会话工具栏、管理二级导航和轨迹返回入口保留。帮助改为操作说明，不再重复介绍开发批次。

7. **复测中发现的窄屏与加载时序问题**：模型配置未读取完成前禁用预设按钮，防止用户刚选好的草稿被迟到读取覆盖；手机轨迹页改用两行快照网格，避免长哈希被事件计数和刷新按钮挤成单字符竖列。两项均新增对应回归断言，不改变配置保存语义或截断证据。

8. **旧首页导航即清空输入、首轮交接过早**：用起始/各会话独立的内存草稿和显式新建确认替代破坏性 reset；创建成功但首轮未接受时仅保留重试候选，不提前绑定可见会话。接受后由持续存在的父页面路由，避免起始输入卸载吞掉回执。

9. **慢/失败读取与已变化的输入容易互相覆盖**：保存草稿时跳过尚未恢复的加载/错误占位，消费提交时比对草稿 ID、场景、文字和附件；同一份尚未确认的草稿不会被重复发送。后台迟到回执不消费后续独立新建的输入。

10. **模态弹窗未完整隔离背景**：保留 Tab/Esc/返回焦点，同时在弹窗打开时隐藏背景的可访问树并设为 inert，关闭时恢复原属性；没有通过改主题色或跳过无障碍检查掩盖问题。

## 4. 视觉与适配

采用浅色企业页面、原有暖橙主色（#DA724D）、轻边界与用途明确的资源图标。主题色按用户要求恢复，企业版布局与功能保持不变。保留彩色场景类别，不依赖 CDN、远端字体或图片。

- 首页收敛为标题、主输入和轻量建议；公共资源和历史通过稳定导航发现，不再重复陈列，不新增运营 KPI 大屏或宣传性装饰。
- 常规资源/管理页只有一组标题区，最大内容宽度 1160px；工作台与空白新会话采用最大 820px 的居中起点。管理二级导航仍与资源页正文网格对齐，不强迫工作台继续使用目录布局。
- 左侧导航不再自动隐藏或点击展开：桌面/平板完整常驻，700px 及以下保留图标与完整文字的常驻窄栏，不做只有图标的隐藏菜单。
- 导航主入口采用 14px / 600、当前项 700；明确本地中文字体回退，确保实际渲染字重。最近会话等次级内容不做同等加粗。手机完整标签为 11px / 600，常驻栏为 92px。
- 产品自带界面、预置场景和工具图标经检查未发现 emoji 图标，均为本地线性 SVG。新增 `check:icons` 门禁并接入 `make lint`；不会清洗用户消息、模型回答或业务文件。
- 会话详情在宽屏可并排，在窄屏作为按需覆盖层。
- 错误、空状态、未接入状态、读取中和审批均有真实可见反馈。
- 支持键盘导航、可访问名称、焦点约束、焦点返回及减少动画偏好。

### 页面布局、账号菜单与帮助：24 项 / 88 个页面 + 11 个菜单布局快照

命令：

```bash
python3 scripts/check-page-layout.py --axe-script /path/to/axe.min.js
```
