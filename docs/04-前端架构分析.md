# 04 · 前端架构分析（frontend）

> 项目：AgentHarness Forge · 技术栈沿用旧 AgentX：**Vue 3 + Vite + TypeScript + Pinia + Element Plus**，最大化平移 ClaudeChat 系组件。

## 一、平移策略一句话

> ClaudeChat 的"骨架"（对话页 + 场景选择器 + SSE 渲染管线）是成熟资产，**结构平移、数据源换约、新增三块面板**（轨迹视图 / 子代理卡片 / 成本条）。

## 二、页面地图与路由

| 路由 | 页面 | 阶段 | 来源 |
|---|---|---|---|

## 四、核心组件设计要点

### 4.1 ScenarioSelect（三级分组）

- 数据源合并：`official（seed）+ 我的（API）+ 团队空间（API，P1）`，沿用旧 `mergeScenarios` 思想，分组渲染；
- 选中动作 = 填 prompt 模板 + 应用能力装配展示（技能/MCP/工具/项目 chips）+ 模型路由标签；
- 官方场景只读可「复制」为我的场景；团队场景卡片带版本徽标（如 `v3`）。

### 4.2 ScenarioEditor（双模式）

- 智能生成默认：描述 textarea + 示例 chips → `POST /agent-scenarios/generate`（后端走 dsh Creative 模式验证）→ 回填装配单，每项标「AI 建议」；
- 手动装配表单字段 → `Bundle` 视图模型：基础信息 / prompt 分区 / 能力（插件·Skill·MCP·工具）/ 模型路由 / 策略 / inputSchema；
- **「试运行」硬性门禁**：未在沙箱跑通一次，保存按钮禁用（产品方案质量红线）。

### 4.3 TrajectoryPanel（差异化体验）

- 左侧会话消息流 + 右侧轨迹面板并排；轨迹按 `source` 过滤（system / llm-thinking / tools / agent / injection）；
- 万级事件用**虚拟列表**（`el-table-v2` 或自绘）；单击事件 → 定位对应消息气泡/工具卡；
- 回放模式 = 只读快照路由 `/agent/trajectory/:sessionId`，带水印与时间轴 scrubber。

### 4.4 SSE 管线（平移改造清单）

| 事件 | 处理 | 变动 |
|---|---|---|
| `session` | 写 store（session_id、bundle 版本徽标） | 字段微调 |
| `message_delta/message` | 正文流式渲染 | 平移 |
| `thinking_delta` | 折叠块（默认收起，标签"思考过程"） | **新增** |
| `tool_use_*`/`tool_result` | ToolCallCard | 平移 + 审批状态徽标 |
| `subagent_dispatch` | SubagentCard 嵌套 | **新增** |
| `approval_required/resolved` | ApprovalDialog + store 待办 | 平移 |
| `cost_tick` | CostTicker | **新增** |
| `files/done/error` | 产物面板/收尾 | 平移 |

## 五、状态设计（stores/agentChat.ts 切分）

```
state: currentScenario(装配视图) | session | phases | streamBuffer |
       pendingApprovals[] | cost {tokens,cost} | trajectoryOpen
actions: pickScenario → 填模板/挂能力 | submit → SSE | resolveApproval |
         fork/replay | openTrajectory
getters: 能力 chips 摘要 / 是否可提交（审批阻塞中禁用连续提交）
```

- 会话恢复：路由 `sessionId` → 拉 snapshot（消息树 + 最新 cost），不等 SSE；
- 断线：SSE 带 `last_event_seq` 重连（后端事件索引支持，见 02-技术方案 §4.3）。

## 六、工程规范与前 4 周前端排期

- 规范：`<script setup lang="ts">` 统一；页面按功能模块放在 `views/<模块>/`（不再有 `views/agent/` 这一层，见下方「当前目录」）；API 层不直接写组件逻辑；类型从 `types/agent.ts` 单源出。
- 联调 Mock：`vite-plugin-mock` 按 SSE 协议造流，前后端可并行开发（事件协议已在 02-技术方案冻结）。
- 排期：W1 脚手架 + SSE 管线平移 → W2 AgentChat + ToolCall/Approval → W3 ScenarioSelect/Editor + generate 联调 → W4 TrajectoryPanel 初版 + 成本条 + 联调收口。
